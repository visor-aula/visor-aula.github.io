# Visor de libros digitales

Visor para el salón que abre libros digitales hechos en Flash, con [Ruffle](https://ruffle.rs).
Funciona en Safari (iPad, iPhone, Mac) y en otros navegadores, y se instala desde el navegador.

Este sitio **no contiene ningún libro**: cada docente agrega los suyos, que se guardan solo en su
equipo (almacenamiento privado del navegador). Nada se sube a internet.

Ruffle se distribuye con sus licencias MIT/Apache (carpeta `ruffle/`).
